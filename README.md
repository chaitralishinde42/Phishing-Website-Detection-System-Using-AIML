# 🛡️ AI-Powered Phishing Website Detection System

## 📌 Project Overview

This project is an AI-powered web application that detects phishing websites using Machine Learning techniques. Users can enter a website URL, and the system predicts whether the website is Safe or Phishing.

The project combines Machine Learning, Feature Engineering, and Flask Web Development to provide real-time phishing detection.

---

## 🚀 Features

- Detects phishing websites from URLs
- Real-time prediction
- Machine Learning Ensemble Model
- Flask Web Application
- User-friendly Interface
- Feature Extraction
- Secure Prediction Pipeline

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/chaitralishinde42/Phishing-Website-Detection-System-Using-AIML.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
